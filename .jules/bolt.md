## 2026-10-18 - Replace map.any? with any? for performance\n**Learning:** Using `.map(&:recommended?).any?` creates an intermediate array and iterates through all elements before checking for truthiness. Using `.any?(&:recommended?)` short circuits early, avoiding the full iteration and saving memory allocation, keeping garbage collection pressure low.\n**Action:** Use `.any?(&:method)` instead of `.map(&:method).any?` when evaluating enumerables in Ruby.
